建立你自己的小幫手話術台

不需要寫程式。複製模板、開啟 GitHub Pages，就能有自己的網站。

3 個步驟完成

1在 GitHub 倉庫首頁按 Use this template。
2選擇 Create a new repository，輸入你的倉庫名稱後建立。
3到新倉庫的 Settings → Pages，Source 選 Deploy from a branch，Branch 選 main 與 /(root)，按 Save。

開始建立話術

開啟 GitHub Pages 網址後，可直接在網站新增話術，或按「下載空白模板」填寫 Excel 後匯入。

記得定期下載 JSON 備份；資料保存在你目前使用的瀏覽器中。

沒有看到 Use this template？

可改按 GitHub 右上角的 Fork 建立副本，然後同樣到 Settings → Pages 開啟網站。
